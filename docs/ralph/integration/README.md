# RALPH integration map

RALPH is embedded in and supported by ZEN Control. `scripts/ralph_profile.py` provides `ZEN_PROFILE`; `scripts/ralph.py`, `scripts/ralph_web.py`, and `scripts/ralph_gate.py` import it for root/state paths, metadata, controller CLI resolution, qualification, and ZEN-only guidance.

The detailed host contract is [ZEN integration](../../zen/ralph-integration/README.md). Its values are neither generic defaults nor package configuration.
