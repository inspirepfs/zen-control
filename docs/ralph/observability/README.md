# RALPH observability map

Embedded evidence is host-local: `.ralph/live.log`, `events.jsonl`, `journal.md`, `reports/`, `usage-ledger.jsonl`, `usage-stats-reset.json`, and the `zen_ralph_web_snapshot_v1` web snapshot. Gate and web readers must never become state authorities.

Event/journal/report lifecycle semantics are core candidates. Paths, ZEN wording, usage provider, console display, retention, and existing `zen_*` identifiers remain adapter or compatibility work.
