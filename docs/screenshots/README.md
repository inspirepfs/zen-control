# Screenshot Capture Checklist

Public screenshots should use synthetic or deliberately sanitized data.

Before committing a screenshot, check for:

- household names or usernames;
- real device names, MAC addresses or IP addresses;
- DNS/domain activity that reveals private browsing/network use;
- private/public deployment hostnames tied to the household;
- QR codes, TOTP secrets or recovery codes;
- Cloudflare, RouterOS, Pi-hole, database or API credentials;
- audit/incident text that embeds identifying details.

Recommended showcase set:

1. Dashboard / connected system health
2. Managed devices
3. Device 360
4. Effective policy explainability
5. Policy Simulation
6. Classification Intelligence
7. Operational Diagnostics
8. Kid Control migration authority summary
