# Screenshot privacy checklist — deferred

Screenshots are **not required for the initial public release** and are deliberately deferred until real product captures can be sanitized and reviewed. Synthetic UI imagery is not used as release evidence.

When real screenshots are added later, check for household names/usernames, real device names/MAC/IP addresses, private DNS/activity, deployment hostnames, QR/TOTP/recovery material, credentials/tokens, and identifying audit/incident text.
